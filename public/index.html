DEVELOPER INTEGRATION

High-speed Validation REST API

Real-time HTTP validation with built-in hardware identification and encrypted payload delivery.

GET /api/v1/validate

Called automatically by your protected script at runtime. Evaluates license validity, checks blacklist status, and enforces HWID hardware binding.

Response Codes

hwid_bound First run: Key valid, hardware ID successfully bound.
hwid_ok Key valid, matches currently registered hardware ID.
hwid_mismatch Key valid but executed on a different unauthorized device.
blacklisted User or device permanently blacklisted from all scripts.
expired / voided License duration has passed or was revoked by admin.

HWID locking captures the buyer's unique hardware identifier (or client device ID) on their very first script execution. From that point onward, that key will only execute on that specific device. If the key is shared with friends or leaked publicly, the API rejects it with an hwid_mismatch error.
