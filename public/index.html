How it works

Set up in four steps

From adding the bot to locking your first customer’s hardware in minutes.

  1. 01

    Add the bot & /claimowner

    Invite Protect-Vmax to your server and claim ownership so only you can manage keys.

  2. 02

    /setup + /bulkgen

    Register your script and generate keys one-by-one or in bulk, with or without expiry.

  3. 03

    /whitelist buyers or /keydrop

    Whitelist buyers manually, or start a public countdown key drop your community can claim.

  4. 04

    Loader calls the API & HWID locks

    Your loader validates each key through the API and locks it to that device on first use.

Loader & API

One line to load. One endpoint to validate.

Ship a single loadstring to your buyers — it fetches your script from the Protect-Vmax host and locks the key to their hardware. Under the hood it validates against GET /api/v1/validate. The response status tells you exactly what to do.

  • hwid_boundFirst run — key is now locked to this device.
  • hwid_okKey valid and HWID matches. Access granted.
  • blacklistedUser is permanently blocked.
  • hwid_mismatchKey used on a different device.
  • expiredKey is past its expiry date.
